# Extract interaction results

Extract interaction results

## Usage

``` r
extract_rna_de_overlap_results(
  limma_results,
  sample_metadata,
  options = list()
)
```

## Arguments

- limma_results:

  Limma results from \`parse_limma_results_contrast()\`.

- sample_metadata:

  sample metadata from \`create_model_frame()\`.

- options:

  epiPot options.

## Value

interaction results
