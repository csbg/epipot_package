# ggplot2 theme for plotting functions

ggplot2 theme for plotting functions

## Usage

``` r
theme_epipot(
  base_size = 10,
  base_family = "Helvetica",
  grid = TRUE,
  rotate = FALSE,
  ...
)
```

## Arguments

- base_size:

  font size

- base_family:

  font familty

- grid:

  whether to draw a grid

- rotate:

  whether to rotate x-axis labels

- ...:

  other options passed to the package

## Value

a ggplot2 theme
