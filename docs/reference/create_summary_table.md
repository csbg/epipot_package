# Make a summary table.

Make a summary table.

## Usage

``` r
create_summary_table(limma_results, final_results_RNA_list, options = list())
```

## Arguments

- limma_results:

  Limma results from \`parse_limma_results_contrast()\`.

- final_results_RNA_list:

  The RNA list from \`extract_rna_de_overlap_results()\`.

- options:

  epiPot options.

## Value

A summar table.
