# Build contrast names

Build contrast names

## Usage

``` r
build_contrast_name(
  pattern_key,
  cell_type,
  disease_condition = NULL,
  options = list()
)
```

## Arguments

- pattern_key:

  key of the replacement pattern in the 'contrast_patterns' option

- cell_type:

  name of the cell type

- disease_condition:

  name of the disease condition

- options:

  epiPot options

## Value

the contrast name
