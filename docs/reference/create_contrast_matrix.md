# Create a contrast matrix for a differential epiPot analysis

Create a contrast matrix for a differential epiPot analysis

## Usage

``` r
create_contrast_matrix(model, sample_metadata, options = list())
```

## Arguments

- model:

  model matrix from \`model.matrix()\`.

- sample_metadata:

  sample metadata from \`create_model_frame()\`.

- options:

  epiPot options.

## Value

a contrast matrix
